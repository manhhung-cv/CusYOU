## 🚀 Hướng Dẫn Cài Đặt Nhanh (Từ GitHub Releases)

Dành cho người dùng thông thường, không cần cài đặt Git hay dòng lệnh:

### Bước 1: Tải bản đóng gói sẵn
1. Truy cập vào mục **[Releases](https://github.com/manhhung-cv/CusYOU/releases/tag/CusYOU)** ở cột bên phải giao diện GitHub của dự án.
2. Tìm phiên bản mới nhất (ví dụ: `v1.5.0`).
3. Trong phần **Assets**, bấm tải tệp **`CusYOU-v1.5.0.zip`**.
4. Giải nén tệp `.zip` vừa tải về vào một thư mục cố định trên máy tính (ví dụ: `D:\Extensions\CusYOU`).
   > *Lưu ý: Không xóa thư mục này sau khi cài đặt, vì trình duyệt sẽ đọc trực tiếp từ đây.*

---

### Bước 2: Nạp tiện ích vào trình duyệt

1. Mở trình duyệt (Chrome, Brave, Edge, Cốc Cốc...) và truy cập đường dẫn quản lý tiện ích:
   * **Chrome / Cốc Cốc:** `chrome://extensions/`
   * **Microsoft Edge:** `edge://extensions/`
   * **Brave:** `brave://extensions/`
2. Bật công tắc **Developer mode** (Chế độ dành cho nhà phát triển) ở góc trên bên phải.
3. Nhấp vào nút **Load unpacked** (Tải tiện ích đã giải nén) ở góc trên bên trái.
4. Điều hướng tới và chọn **thư mục bạn vừa giải nén** (thư mục chứa file `manifest.json`).
5. **Kiểm tra thành công:** Extension `CusYOU` sẽ xuất hiện trong danh sách kèm phiên bản hiển thị tương ứng.

---

### Bước 3: Ghim và Sử dụng

1. Bấm vào biểu tượng **Mảnh ghép** (Extensions) trên thanh địa chỉ của trình duyệt, chọn biểu tượng **Ghim (Pin)** cạnh `CusYOU`.
2. Mở [YouTube](https://www.youtube.com) và tải lại trang.
3. Nhấp vào icon CusYOU trên thanh công cụ hoặc bấm vào nút điều khiển tích hợp sẵn ở góc dưới bên phải trình phát video để tùy chỉnh.
